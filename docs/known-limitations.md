# Known Limitations & External Boundaries — Agent Assurance Laboratory

Reference: `01_Product_and_Engineering_Design.docx` (§1, §2, §10) and `03_Business_Model_and_Configurable_Pricing.docx` (§1, §6)

## 1. Methodological & Evaluation Limits

1. **Synthetic & Bounded First**:
   The MVP is designed for bounded, controlled evaluations against authorized sandbox endpoints and the bundled synthetic test agent. It does not perform autonomous live penetration testing or unrestricted red teaming on uncoordinated third-party systems.
2. **Telemetry Dependency**:
   Safety verdicts require observable telemetry (tool event execution logs and state assertions). If a target agent hides tool calls or fails to provide telemetry, the deterministic oracle will return `INCONCLUSIVE`. Verbal refusal text in an agent's response is never accepted as proof that a tool was not executed.
3. **No Legal or Regulatory Certification**:
   Assessments, findings, and reports generated by this platform do **not** constitute legal compliance opinions, regulatory certifications (e.g. EU AI Act conformity assessments), or cyber insurance warranties. Mappings to OWASP Agentic Top 10 (2026) and NIST AI RMF GenAI Profile (NIST AI 600-1) are governance and discovery references, not certification claims.
4. **Explicitly Out-of-Scope Capabilities (Doc 1 §2)**:
   - Unrestricted internet crawling
   - Arbitrary customer code execution inside evaluation workers
   - Autonomous exploitation of third-party systems
   - Production credential harvesting
   - Real-world financial transaction execution

## 2. External Dependencies & Cloud Account Prerequisites

To deploy the production Terraform configuration and connect live external services:
- **Google Cloud Project**: Active GCP project with billing enabled for Cloud Run, Cloud Tasks, Cloud Storage, and BigQuery.
- **Identity Platform / Firebase**: Firebase Admin credentials required for remote Bearer token verification when `AUTH_DISABLED=false`.
- **Domain & SSL**: Valid domain and managed SSL certificate for custom public endpoints.
- **Stripe / Payment Gateway**: Commercial prices (£1,500 Starter, £3,500 Pro, £650 Team, £1,750 Growth) are commercial hypotheses for buyer testing; live payment processing requires a provisioned Stripe account and webhook signing keys.

## 3. Disclaimers for Buyers & Risk Authorities

- Reports generated represent the state of an agent at the specific timestamp and scenario pack version evaluated.
- Any change to the upstream foundation model, system prompt, or tool permissions requires a re-run in the Regression Studio to establish ongoing safety evidence.
